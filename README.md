# Evaluación Sistemática JavaFX

## Descripción

Aplicación de escritorio desarrollada con JavaFX, FXML, Maven y Lombok. El sistema permite iniciar sesión y gestionar registros de colaboradores mediante operaciones CRUD como agregar, actualizar, eliminar y visualizar registros.

## Integrantes

- Juan Roman
- Andy Diaz

## Instrucciones

1. Clonar o descargar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Verificar que se esté utilizando JDK 21.
4. Recargar las dependencias de Maven.
5. Ejecutar la clase `Launcher.java`.
